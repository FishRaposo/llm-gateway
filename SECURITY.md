# Security policy

The gateway's trust boundaries, defense-in-depth request path, secret handling and
operator checklist live in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Open a [security advisory](https://github.com/FishRaposo/llm-gateway/security/advisories/new)
or email fishraposo@gmail.com with the subject `[llm-gateway security]`. Please do
not open a public issue for a security report.

## Supported versions

Security fixes target the latest tagged release and `main`.
