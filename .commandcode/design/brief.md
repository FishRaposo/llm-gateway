# Design brief — LLM Gateway

**Name:** LLM Gateway
**Category:** Public engineering evidence report.
**User:** A recruiter, engineer or client checking the claim, the finding and the evidence.
**Job:** Read the result, the evidence and the remaining limits without hunting.
**Artifact:** `docs/audit/index.html` and the site-hosted `llm-gateway-audit/` copy
**Evidence:** The report's findings, probe/test references, source links and explicit scope/limits.
**Drift to refuse:** GitHub-dark default, decorative dashboard hero, tiny labels, unreadable wide tables, links without a target.
**Register:** Documentation / evidence report.
